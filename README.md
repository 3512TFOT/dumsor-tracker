# DumsorTracker Ghana ⚡

Real-time electricity outage tracker for Ghana, based on the official ECG Load Management Schedule.

## Features
- 🔍 Search any area in Ghana (Accra, Ashanti, Tema, Volta, Western/Eastern/Central)
- ⚡ Live power status for your area
- 📅 Personal weekly outage schedule (Group A / B / C)
- 🔔 Push notifications 1 hour before outages
- 📆 Export to Google Calendar / Apple Calendar / Outlook
- 💬 Community reporting — confirm or report power status
- 📍 Geolocation support

## Data Source
ECG Official Load Management Schedule — April 25 to May 1, 2026

## Tech Stack
- React + Vite
- Vanilla CSS (glassmorphism design)
- Lucide React icons
- Browser Notifications API
- Web Share API
